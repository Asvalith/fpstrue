# 展示范围与来源

本 main 展示的是项目实现与可追溯的实验方法，不是完整可玩的资源包。

## 保留

- `Source/`：角色/武器/GAS、多人接纳与恢复、行为树/EQS/群体管理、性能分级和自动化测试。与开发提交 `fb1b7a3022842f84dac975f3e5293ba0a901d3d0` 的 Source 树一致，树标识 `d45dbdf8b88887c006adc971bf0785138af5f544`；没有删掉必要校验另做一版演示逻辑。
- `Config/`、uproject 与构建目标：可检查默认模式、碰撞、插件和配置选源。参数/资源路径不代表对应 Content 已分发。
- `Tools/`：生成与检查蓝图契约、采集/分析方法及联机回归入口。LegacyPerformance 明确是历史工具，不作为当前基线入口。
- 当前介绍、实现链路、限制、逐项测试结果、脱敏门禁及精选性能图表；历史实验与新构建分开。

## 不放入当前展示快照

Content/第三方素材、生成/打包目录、原始 Trace/ETL/日志、账号/连接凭据、机器身份、私人复习笔记、资产备份和长篇历轮项目说明。脚本中的默认本机引擎路径只是可覆盖的开发默认值，不是必须复用的部署目录。

公开 JSON 采用字段白名单：原状态、警告数、失败门禁和原报告 SHA-256 保留；不补写通过，不把计划、未运行或空数据当作 0 开销。主业务源码未因脱敏改变。

## 推荐审阅顺序

1. [实现链与取舍](INTERVIEW_GUIDE.md)：先理解谁拥有状态。
2. WeaponComponent / CombatAbilities：输入、准入、执行、确认和换弹唯一时钟。
3. SurroundManager / EnemyAIController / EnemyBehaviorTree：资源分配和个体执行。
4. EnemyPerformance 与 [线程/模块证据](Testing/160ai-20261024.json)：分级是否落到消费者，等待中是否包含任务工作。
5. [验收记录](REFACTOR_ACCEPTANCE.md)：同时看成功、警告及未闭环项。

当前快照不带二进制资产；没有强推或清除 Git 历史，也不对其他分支中的资源作新的授权承诺。
