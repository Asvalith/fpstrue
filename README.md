# UE5 多人 FPS · 战斗同步与群体 AI

基于 UE5.5、C++ 与蓝图独立实现多人 PvPvE 射击，完成装备、射击换弹、伤害死亡、计分重生、敌人战斗与 HUD。主要实践逐发同步与预测校正、群体调度和线程性能分析。

> `main` 是源码展示快照，需要有授权的 Content 资源才能运行；不分发素材、原始日志、凭据或缓存。源码来自开发提交 `18c9648`，Source 树与开发提交一致，没有另写展示玩法。[公开范围](Docs/SHOWCASE_SCOPE.md)与[资源依赖](Docs/ASSET_REQUIREMENTS.md)说明边界。

## 实现链路

1. **战斗同步**：GAS 处理激活、互斥与取消；武器组件唯一管理弹药与执行队列。本地预测弹药和换弹表现，服务器按真实武器、装备代际、轮次与 ShotId 裁决；快照水位避免重复扣弹。逐发输入用有界不可靠批次，快速裁决窗口配合可靠终结兜底。
2. **网络时间与恢复**：同一探测分别估计动态 RTT/波动与服务器时钟偏移；CMC 负责移动预测/重放，玩家历史形状用于命中查询。断线时保留服务器真实对象，轮换票据后重新占有，离线伤害和死亡继续生效。
3. **群体 AI**：感知进入行为树；每目标管理内外圈资格、FIFO 晋升与固定候补，单次攻击许可独立。共享 EQS 缓存，复用路径、失败退避与 World 帧预算限制重复 MoveTo。
4. **性能分级**：服务器计算玩法重要性并发放逻辑档位；客户端按自己视图决定动画、阴影和光追预算，使用降频、错峰与 Animation Sharing。结合线程 CPU、嵌套任务和渲染等待链定位工作与等待。

## 架构边界

- 只有一个多人 GameMode。GameInstance 管本机连接，GameMode 管权威规则，GameState/PlayerState 发布公共事实。
- C++ 维护规则、状态和生命周期；蓝图负责角色/武器美术装配、动画图、声画资源和 HUD 布局。Data Asset 保存共享配置，运行态留在各自所有者中。
- 开发场景位于 `Testing/`。已删除 Foot IK、AI 世界血条、旧 Profile 采集器及无人消费的公共射击字段；保留唯一 Baseline 入口，没有空兼容接口。
- 网络协议为6，两端需一起重建。没有自研 UDP/RTO；GAS 可靠激活仍可能等待，不能把不可靠逐发输入称为消除了所有队头阻塞。

**仍有边界：**弱网、真实渲染与高速横移叠加的一轮未通过：首发到达时，目标显示时间已超出350ms历史窗口，未命中玩家。失败原样保留，不扩大历史窗口或把分项通过代替组合通过。上述单轮功能实测也不证明160 AI容量、发布包、公网或商业FPS等级。

最后的160AI首包丢失诊断也复现了激活授权等待，存在过期拒绝，未通过容量验收。历史GPU/等待链实验保留原口径，本轮没有把旧13.28ms或70.4%改写为新结果。[本轮白名单摘要](Docs/Testing/fps-network-20261026.json)、[网络合同与预算](Docs/FPS_NETWORK_ACCEPTANCE.md)与[验收记录](Docs/REFACTOR_ACCEPTANCE.md)同时记录通过、失败和未覆盖范围。
